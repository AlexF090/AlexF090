### About Me

I build accessible, maintainable and user-focused web applications with modern frontend technologies.

Most of my day-to-day work is architecting and maintaining a production-grade React/TypeScript application — feature ownership, dependency security, and keeping a growing codebase pleasant to work in matter more to me than shipping something once and walking away.

My strengths lie in **clean architecture**, **consistency in UI/UX** and improving **developer experience** within teams. I enjoy environments where thoughtful code, real testing practices and honest collaborative discussion lead to long-term stability instead of short-term shortcuts.

### Open Source & Contributions

I regularly contribute small fixes, refactoring improvements and accessibility enhancements to open source projects — a few have landed often enough that GitHub started handing out shark-themed badges for it.

Examples include:

- **Home Assistant** ecosystem improvements
- **[scrypted](https://github.com/koush/scrypted)** — merged contribution
- Minor bug fixes and clean-up in community libraries and tooling where clarity helps others

I also maintain a couple of small tools of my own — security is something I care about beyond just following best practices at work, and both of these grew out of that:

- **[outdated-plus](https://www.npmjs.com/package/outdated-plus)** — a zero-dependency CLI that extends `npm outdated` with publish dates and package age, so you can actually see how stale a dependency is before touching it.
- **[eslint-plugin-unicode-comments](https://www.npmjs.com/package/eslint-plugin-unicode-comments)** — an ESLint plugin that flags dangerous Unicode characters in code (Trojan Source / homograph-style attacks, invisible characters, lookalike quotes) before they cause problems.

I don't wait for permission; if I notice something that improves developer experience or correctness, I open a PR.
